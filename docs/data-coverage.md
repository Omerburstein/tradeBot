# Data Coverage — Decision Completeness (TODO #6)

The algo only makes an entry/exit decision for a slot when **all four** of its
required data sources are present. If any is missing it emits a structured
`DATA_GAP` error and holds — a half-covered slot never moves the book. This
file documents what each source is, where it comes from, and what "present"
means, then reports which slots currently lack full coverage.

> Generated by `npm run coverage`. Do not edit by hand — rerun to refresh.

## Required sources

| Source | Table | Column(s) | Present when |
|---|---|---|---|
| `spx` | `spot_prices` | `spot` | a spot_prices row exists at the slot captured_at (a finite SPX price). |
| `es` | `es_prices` | `close` | an es_prices row exists at the slot captured_at (a finite ES close). |
| `gex` | `periscope_snapshots (panel = gamma)` | `value` | at least one in-window strike carries a non-zero gamma at the slot. |
| `positions` | `positions` | `call_qty + put_qty` | at least one positions row exists at the slot captured_at (net MM contracts). |

A slot is **actionable** only when every row above is satisfied. The gate lives
in `algorithms/data-coverage.ts` (`assessCoverage`) and is enforced in
`algorithms/signal-generator.ts` (`processSnapshot`, step 0). Intermediate
5-minute price ticks additionally require a spot **and** ES bar at the tick
instant; their GEX/positions carry from the parent 10-minute Greek slot.
